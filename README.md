# 灵机一记 (LingJiYiJi)

嘿！这是我自己写的一个 macOS 小工具，专门用来随手记下脑子里那些一闪而过的灵感。

[!Note]后续可能要做
> - 后续会考虑Andriod、Windows版本
> - 会考虑云端数据同步
> - 会考虑wx快速发感想同步数据（公众号功能）

### 💡 为什么写这个
平常是不是会有一些小点子，其实平常会用TODO和博客做记录，但是还是想做一款单独**快速记录灵感**的工具，由此有了它的出现。

另外记了想自动提醒我，就设置了第二天晚上十点提醒

另外关于分类的话，可以自己添加、自己设置类别，当然也可以用AI直接分类
